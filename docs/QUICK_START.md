# DiskMap 1.0 빠른 시작

개인용 저장 공간 분석·정리 앱입니다. 이 설치본은 Apple Silicon용이며 macOS 14 이상을 대상으로 빌드했습니다. 실제 실행 검증은 이 맥의 macOS 26.6.2에서 했습니다.

## 실행·설치

프로젝트의 `dist/DiskMap.app`을 두 번 클릭하면 실행됩니다. 계속 사용할 때는 사용자가 직접 이 앱을 응용 프로그램 폴더로 복사하면 됩니다. 작업 중에는 프로젝트 밖에 앱을 설치하지 않았습니다.

보관용 `DiskMap-1.0.0-arm64.zip`에는 같은 앱이 들어 있습니다. 먼저 압축을 풀고 실행하세요. 개인용 ad hoc 서명이며 Developer ID 서명·Apple 공증은 없습니다. 다른 맥으로 다운로드한 사본은 macOS가 실행을 제한할 수 있습니다. 경고가 나타나면 직접 만든 설치본인지 확인하고 [Apple의 앱 열기 안내](https://support.apple.com/ko-kr/102445)를 참고하세요.

## 분석하고 정리하기

1. **폴더 선택** 또는 `⌘O`로 정리하고 싶은 폴더를 선택합니다. 스캔은 내용을 열거나 파일을 변경하지 않습니다. **취소**하면 이전 결과를 유지합니다.
2. 원형 차트의 큰 조각을 살펴보세요. 폴더를 더블 클릭해 들어가고, 가운데 버튼이나 상단 경로로 돌아옵니다. 오른쪽 목록에서도 파일을 선택할 수 있습니다.
3. `⌘F`로 이름을 검색합니다. **하위 포함**을 켜면 안쪽 폴더까지 찾습니다. 용량 정렬과 필터로 큰 파일을 좁힐 수 있습니다.
4. 지워도 되는 항목만 **정리 목록에 담기**로 모읍니다. 폴더를 담으면 내부 파일 전체가 포함됩니다. 담기·빼기·목록 비우기는 실제 파일을 바꾸지 않습니다.
5. **목록 검토**에서 전체 경로와 포함 파일 수를 확인합니다. **휴지통으로 이동…**를 누른 뒤 최종 확인창에서 확인해야 실제 이동합니다. 바뀌었거나 확인할 수 없는 항목은 건너뜁니다.
6. 결과에서 성공·실패·건너뜀 사유를 확인합니다. 완료 후 자동 재스캔하며 변경되지 않은 남은 후보만 유지합니다. 중단하면 아직 시작하지 않은 항목을 건너뜁니다.

## 용량과 제한

- 차트는 실제 디스크에 **할당된 용량** 기준입니다. 압축·희소 파일·하드 링크 때문에 파일 크기와 다를 수 있습니다.
- 휴지통으로 옮겨도 파일은 디스크에 남습니다. 이동 용량은 확보된 여유 공간이 아닙니다. 복원·휴지통 비우기는 사용자가 Finder에서 직접 합니다.
- 접근할 수 없는 폴더, 링크, 앱·사진 보관함 패키지, 알려진 클라우드 경로와 미다운로드 항목은 제외하며 **부분 집계**로 표시합니다. 부분 집계 항목을 0바이트로 해석하지 마세요.
- 정리는 내장 로컬 디스크만 지원합니다. 시스템·설정·민감 경로는 보호합니다. 계속 수정되는 파일이나 폴더는 관련 작업을 멈추고 다시 스캔한 뒤 정리하세요.
- 최근 위치와 표시 조건만 기기에 저장합니다. 검색어·후보·실행 결과·파일 트리는 저장하지 않으며 앱은 자동으로 이전 위치를 스캔하지 않습니다. 분석 내용 전송과 네트워크 기능은 없습니다.

프로젝트 `dist`에서 실행한 앱은 `.diskmap-state/preferences.json`을 사용합니다. 설치한 앱은 `~/Library/Application Support/DiskMap/preferences.json`을 사용합니다. **최근 위치 → 기록 지우기**는 기록만 지웁니다.

접근 오류가 나면 읽을 수 있는 하위 폴더를 선택하세요. 스캔 후 내용이 바뀌었다면 다시 스캔하고 후보를 다시 검토합니다. 복원은 **휴지통에서 보기**를 눌러 Finder에서 진행합니다. 앱은 영구 삭제나 휴지통 비우기를 제공하지 않습니다.
